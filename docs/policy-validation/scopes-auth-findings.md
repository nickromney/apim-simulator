## Explicit scope and remaining fidelity

The expression engine implements a bounded C# compatibility layer; running the six initial examples does not establish all members in the guide's extensive .NET reference table. Python private attributes are rejected to keep the evaluator's namespaces from exposing host runtime internals. The authored role-dependent filtering test demonstrates the authoring guide's prompt outcome; it does not claim a connection to a Copilot authoring service.

Named values support separate display names and automatic reference updates. Set `APIM_LOCAL_VAULT_BASE_URL` and `APIM_LOCAL_VAULT_KEY` to opt into the local vault simulation; placeholder secret IDs such as `https://vault.example.test/secrets/name` are mapped by path, with no external-network fallback. The broker provides separate admin-write and reader-only roles; rotation is immediate in local runs. `APIM_NAMED_VALUE_<RESOURCE_ID>` remains the highest-priority environment override. Reader failures, oversized responses, and values outside 1–4096 characters fail resolution. `tests/test_named_value_guide_lifecycle.py` verifies renaming, masking, mapping, bounds, and rotation through consecutive gateway requests. The live helper exercises vault rotation when passed the broker client.

Management and trace output keep secret masking according to the simulator's existing conventions. An operator with policy authoring access can still emit the secret in a gateway header, as the source sample demonstrates.

GraphQL SQL and Cosmos data sources appear as links in the guide; its executable resolver samples use HTTP data sources. HTTP schema/resolver/query behavior is what this evidence establishes.
